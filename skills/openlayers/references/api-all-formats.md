# OpenLayers Complete API Specification — All Format Classes (`ol/format/*`)

Source: https://openlayers.org/en/latest/apidoc/module-ol_format_Feature-FeatureFormat.html

---

| Format Class | Import Path | Description |
| :--- | :--- | :--- |
| `GeoJSON` | `ol/format/GeoJSON.js` | RFC 7946 GeoJSON parser/writer (`readFeatures`, `writeFeatures`). |
| `MVT` | `ol/format/MVT.js` | Mapbox Vector Tile protobuf binary parser. |
| `KML` | `ol/format/KML.js` | OGC Keyhole Markup Language (Google Earth format, styles, icons). |
| `GPX` | `ol/format/GPX.js` | GPS eXchange format (tracks, waypoints, routes, elevation). |
| `TopoJSON` | `ol/format/TopoJSON.js` | Shared boundary topology format. |
| `WKT` | `ol/format/WKT.js` | Well-Known Text geometry parser/writer (`POINT(14 50)`). |
| `WKB` | `ol/format/WKB.js` | Well-Known Binary geometry parser. |
| `GML3` / `GML2`| `ol/format/GML3.js` | OGC Geography Markup Language (WFS XML). |
| `EsriJSON` | `ol/format/EsriJSON.js` | ArcGIS REST feature geometry format. |
| `IGC` | `ol/format/IGC.js` | Flight recorder format (paragliding/gliding GPS data). |
| `Polyline` | `ol/format/Polyline.js` | Google Encoded Polyline algorithm parser. |
| `OSMXML` | `ol/format/OSMXML.js` | Raw OpenStreetMap XML format. |
