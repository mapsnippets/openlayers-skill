# OpenLayers Complete API Specification — All Control Classes (`ol/control/*`)

Source: https://openlayers.org/en/latest/apidoc/module-ol_control_Control-Control.html

---

| Control Class | Import Path | UI Functionality |
| :--- | :--- | :--- |
| `Zoom` | `ol/control/Zoom.js` | `+` / `−` zoom buttons. |
| `ZoomSlider` | `ol/control/ZoomSlider.js` | Vertical/horizontal continuous zoom track slider. |
| `ZoomToExtent` | `ol/control/ZoomToExtent.js`| Button that zooms directly to a predefined bounding box. |
| `Rotate` | `ol/control/Rotate.js` | Compass arrow resetting rotation to North (`0` rad). |
| `Attribution` | `ol/control/Attribution.js`| Copyright and data provider notice (collapsible on mobile). |
| `ScaleLine` | `ol/control/ScaleLine.js` | Metric, imperial, nautical, or US scale bar/line. |
| `FullScreen` | `ol/control/FullScreen.js` | HTML5 Fullscreen API toggle button. |
| `MousePosition` | `ol/control/MousePosition.js`| Real-time pointer coordinate display with custom formatting and projection. |
| `OverviewMap` | `ol/control/OverviewMap.js`| Mini inset map showing current viewport position. |
| `Control` (Base) | `ol/control/Control.js` | Extensible base class for custom buttons, search bars, and HUD panels. |
